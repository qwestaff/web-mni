# МвПРОР — СибГИУ

Веб-система многовариантной профориентации на основе количественной оценки структуры интеллекта. Проект помогает пройти авторские тесты и комплексный вопросник, определить типологический спектр интеллектуальных способностей и получить подборку подходящих профессий.

## Визуализация


## Основные возможности

- **4 авторских теста**: дихотомический тест (Филатова, Накрохина), вопросник Крегера, вопросник Седых, вопросник Филатовой
- **Комплексный тест** (52 вопроса, все авторы) для всесторонней типологизации
- **Количественная оценка структуры интеллекта** по четырём шкалам: интроверт/экстраверт, мыслящий/чувствующий, интуит/сенсорик, решающий/воспринимающий
- **Построение типологического спектра** из 16 комбинаций типов с расчётом доли каждого типа
- **Подбор профессий** по вычисленному психологическому профилю
- **Сохранение прогресса и результатов** в локальном хранилище браузера (localStorage)
- **Экспорт результата в PDF** через окно печати браузера
- **Адаптивный интерфейс** на React, Tailwind CSS с графиками на Recharts

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/qwestaff/web-mni
cd web-mni
npm install
```

Запуск в режиме разработки:

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.

Доступные скрипты:

| Команда | Назначение |
|---------|------------|
| `npm run dev` | Запуск dev-сервера Vite с горячей перезагрузкой |
| `npm run build` | Продакшен-сборка в папку `dist` |
| `npm run preview` | Локальный предпросмотр собранного приложения |

## Использование

После запуска перейдите на главную страницу `/`, выберите один из тестов и пройдите его.

### Основные маршруты

| Путь | Описание |
|------|----------|
| `/` | Главная страница с описанием методики и списком тестов |
| `/test/:slug` | Прохождение выбранного теста |
| `/result` | Страница с результатом: профиль, спектр типов, профессии |

### Доступные тесты (параметр `slug`)

| slug | Название | Автор | Вопросов |
|------|----------|-------|----------|
| `fkr` | Дихотомический тест | Филатова, Накрохина | 40 |
| `kreger` | Вопросник Крегера | Крегер | 4 |
| `sedyh` | Вопросник Седых | Седых | 4 |
| `filatova` | Вопросник Филатовой | Филатова | 4 |
| `all` | Комплексный тест (рекомендуемый) | Все авторы | 52 |

### Пример кода (расчёт профиля)

```js
import { buildProfile, calcTypeSpectrum } from './src/lib/resultLogic.js';

const profile = buildProfile('all', questions, answers, sliders);
const spectrum = calcTypeSpectrum(profile);
console.log(spectrum[0].type); // доминирующий тип, например 'ЭвИМР'
```

Основные параметры теста вводятся через интерфейс: ответы на choix-вопросы (`answers`) и положение ползунков для slider-вопросов (`sliders`). Результат рассчитывается автоматически при завершении теста и отображается со спектром типов и подбором профессий.

## Структура проекта

```text
web-mni/
├── index.html              # Точка входа HTML
├── vite.config.js          # Конфигурация Vite (плагин React, чанки)
├── tailwind.config.js      # Конфигурация Tailwind CSS (цвета, шрифты)
├── postcss.config.js       # Плагины PostCSS (Tailwind, Autoprefixer)
├── tsconfig.json           # Конфигурация TypeScript
├── package.json            # Зависимости и npm-скрипты
├── logo_sibsiu.png         # Логотип СибГИУ
├── public/                 # Статические ресурсы
├── src/
│   ├── main.jsx            # Точка входа React-приложения
│   ├── App.jsx             # Роутинг (React Router)
│   ├── index.css           # Глобальные стили
│   ├── components/         # Переиспользуемые UI-компоненты
│   │   ├── test/           # Компоненты прохождения теста (вопросы, навигация, прогресс)
│   │   └── result/         # Компоненты страницы результата (профиль, спектр, профессии)
│   ├── data/               # JSON-данные: вопросы тестов, профессии, маппинг типов
│   ├── lib/                # Бизнес-логика: расчёт профиля, спектра типов, профессий
│   ├── pages/              # Страницы: Home, TestPage, ResultPage, NotFound
│   └── store/              # Zustand-хранилище состояния теста (с persistent в localStorage)
├── dist/                   # Сборка для продакшена (генерируется npm run build)
└── node_modules/           # Установленные зависимости
```
